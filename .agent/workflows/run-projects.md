---
description: How to run the Vinh Khanh Web and App frontends
---

### 1. Run Web Frontend (Vite)
// turbo
1. Open terminal and run:
   ```powershell
   cd frontend/web; npm install; npm run dev
   ```

### 2. Run App Frontend (Expo)
// turbo
1. Open another terminal and run:
   ```powershell
   cd frontend/app; npm install; npm start
   ```
