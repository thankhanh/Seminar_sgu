# Seminar_sgu

## Tech Stack
- React Native
- React Navigation
- Expo
- Tailwind CSS
- React Native Vector Icons
- React Native Safe Area Context

## Installation Guide for Customers
1. Clone the repository:
2. Install dependencies:
```bash
npm install
```
3. Run the app:
```bash
npx expo start
```
4. Download the app from the Expo Go app on your mobile device.
5. Scan the QR code displayed in the terminal with your mobile device.
6. The app should now be running on your mobile device.
